Why this folder exists

  • Provide short, high-signal reading paths for day-to-day project understanding.
  • Keep HTML pages as the direct editable artifacts for human-facing overview content.
  • Preserve metadata and source traceability within each HTML page.

HTML-only metadata convention

Each page embeds a JSON metadata block in <script type="application/json" id="doc-metadata"> with:

doc_audiencedoc_focuscontext_tagsagent_load_hintsource_docslast_updated
