Why this folder exists

  • Provide short, high-signal reading paths for day-to-day project understanding.
  • Keep docs/*.md as source of truth and generate human-facing HTML from that source.
  • Preserve metadata and source traceability within each HTML page.

Generation + metadata convention

Generation behavior is configured in human-output.config.yml. Each page embeds a JSON metadata block in <script type="application/json" id="doc-metadata"> with:

doc_audiencedoc_focuscontext_tagsagent_load_hintsource_docslast_updated

Session workflow (recommended)

  1. Update canonical content in docs/*.md.
  2. Read docs/human-overview/human-output.config.yml and regenerate configured *.html pages.
  3. Keep doc-metadata JSON accurate for focus, tags, load hint, and source traceability.
  4. Add a short visible "What's changed" section for refreshes that change meaning.

Local preview

The markdown viewer needs HTTP mode (not file://).

  1. From repo root, run: python -m http.server 8080
  2. Open: http://localhost:8080/docs/human-overview/index.html
