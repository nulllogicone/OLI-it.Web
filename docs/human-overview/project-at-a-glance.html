One-sentence summary

OLI-it.Web is a modern rebuild of OLI-it: a soulmate-style semantic matchmaking system that connects people by intent and fit, not popularity.

Why this exists

  • Turn the protocol into an elevator pitch: "find meaningful matches through semantic intent, not social noise."
  • Preserve proven SQL matchmaking logic while rebuilding the platform for clarity, maintainability, and future evolution.

Protocol flow

  1. Stamm creates PostIt.
  2. Angler filters define recipient intent.
  3. SQL matching decides valid pairs.
  4. TopLab answers continue the loop.

Architecture pillars

  • Database-first EF Core
  • Stored procedure matchmaking
  • German schema names preserved
  • .NET 10 Razor Pages modernization
